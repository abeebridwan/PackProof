## Camera and editing direction

Use one adult actor as parent and two clearly staged shop setups; no infant needs to appear or consume anything. Print separate item/package marks for FP-1001/PK-2001 and FP-1002/PK-2002. The second unit’s issuer notice must explain the actual wrapper variation shown. Both demo props carry a visible “DEMO — NOT FOR CONSUMPTION” label.

Keep phone screens large and readable. Record screen capture plus a wide camera view proving both physical devices. Show the QR animation at its measured rate; do not speed it up. Freeze the signed result briefly, not the challenge. Mute music for refusal, human consent and tamper rejection. Use a soft click for tool results and a single restrained success sound; no threatening sound effects about the child or seller.

Actual elapsed time can exceed a scene slot: label any cut “Processing time shortened,” retain the measured duration caption, and preserve the uncut run for the repository. Do not edit a failed run into an apparent successful one. All future montage graphics remain labeled concepts. Optional radio audio must be an approved, sourced bulletin; do not insert unreviewed accusations.

## Source captions

- **S1, 0:10–0:16:** “NAFDAC Public Alert 06/2026 · 12 Feb 2026 · altered date markings.” [Official alert](https://nafdac.gov.ng/public-alert-no-06-2026-alert-on-revalidated-infant-formula-sma-gold-found-on-sale/). It reports alleged gastrointestinal distress in a four-month-old infant; it does not establish a death. Narration avoids claiming causation.
- **S2, 0:16–0:22:** “NAFDAC Public Alert 018/2026 · 12 Mar 2026 · suspected counterfeit/unregistered Cerelac.” [Official alert](https://nafdac.gov.ng/public-alert-no-018-2026-alert-on-counterfeit-and-unregistered-cerelac-found-on-sale/). Cerelac is infant cereal; do not relabel it as formula. Preserve the alert’s specific scope.
- **S3, 0:22–0:30:** “OECD/EUIPO 2025 report · estimated US$467bn counterfeit trade · 2021 data · all products.” [Report](https://www.euipo.europa.eu/en/publications/mapping-global-trade-in-fakes-2025). This is historical global context, not infant-formula losses or PackProof’s addressable revenue. If the report cannot be checked during final production, omit the number and retain the two verified alert cards.
- **Model caption, 2:31–2:45:** “Muse Glimmer 30B · Apache 2.0 · [actual provider/model] · cloud inference.” [Meta model documentation](https://dev.meta.ai/docs/muse-glimmer). Fill runtime/provider measurements from the implementation log; never invent them.

Put full links in the video description/README so the short on-screen citations remain legible. NAFDAC pages and Meta documentation were read on 30 October 2026. Do not claim medical advice, chemical testing, official brand enrollment or a live regulatory integration.

## Contingency edits with the same runtime

**No Glimmer or local student:** Replace 2:31–2:45 with the real gate trace and same parent’s outcome. **HOST:** “The useful result is simple: one unsupported handover stopped, one authorized transfer recorded, and a packaging question answered. Every finding points back to evidence the buyer can inspect.” This is the default core-only cut; all other timings stay unchanged.

**Glimmer cloud works, student does not:** Use the main table’s cloud dialogue. Show only the real cloud run and a small “Student experiment — not implemented” caption if it was merely planned. Do not fill the scene with a fake training animation.

**Student trained and runs on Android:** Replace 2:31–2:45 with actual airplane-mode student output beside its cached input. **HOST:** “Glimmer taught a small student this narrow task: explain cached evidence and suggest the next check. Here it runs on Android without internet. Cryptographic checks remain separate.” Caption actual student base, 20 training examples, held-out test count, file size, RSS and latency. No claim the student is itself Glimmer 30B.

**Quick Share, not Bluetooth-only payload:** Keep 2:04–2:31 timing. Replace “A nearby phone passes a small signed pack” with “Nearby sharing passes the signed pack using local Wi-Fi.” Caption “Bluetooth discovery + local Wi-Fi payload; internet off.” Show the actual enabled radios.

**No working local transfer:** Same offline slot, use a pack downloaded earlier. **HOST:** “The buyer downloads a small signed pack before going offline. After closing and reopening the app, this phone checks it locally and shows the packaging notice and snapshot date.” Then the same tamper/status lines. Caption “Predownloaded; nearby transfer not demonstrated.” Do not animate an unbuilt transport.

**No radio bulletin:** Keep the future montage; radio is a labeled concept, not played as a live station. If essential Muse/SAM or the live handshake fails, this is not a completed core demo: fix it or explicitly label the missing feature. No contingency script fabricates those successes.

## Production checklist

- Run the core once uncut; capture actual provider trace, permissions, failed/accepted handovers and receipt recovery.
- Record both devices/radios, offline cold reopen, useful notice and tamper refusal; retain raw recordings privately with consent.
- Use only fictional props, controlled demo identities, owned/licensed music and original footage; keep credentials/private keys out of frame.
- Reconcile dialogue with actual observed results, fill measurement captions, verify source captions, and select the correct model/transport variant.
- Export at 1080p with captions and readable phone crops. Confirm runtime ≤180 seconds, public repository and accessible video/live URLs before submission.
